# 通用 Word 填空模板

正式生成使用 `templates/cwh_fill_in_template.docx`。不让模型修改 Word、设计章节、配色或图形，不把基准报告当本期事实。`scripts/cwh_docx_template.py` 是开发维护工具；正常运行只加载随 Skill 打包的 Word。

## 谁填什么

热词同时保留核心议题与具体关切。通常优先原文真实出现、语义完整的2—6字短概念，不把完整议程或法规标题当词云清单，也不机械截字。核心词须独立可理解；具体关切词可以依托本题理解，模型须明确标为supporting、standalone_topic_label=false、contextual_topic_label=true，并说明真实政策对象与含义。该区分同步适用于原始表和标准表；原文匹配、议题映射、泛词/残片排除、独立复核不取消，不由脚本替模型填写语境审核结论。

| 填充区 | 固定部分 | 本期输入及依据 |
| --- | --- | --- |
| title | 日期＋国务院常务会议舆情综述 | 会议日期，不用提交日 |
| opening | 主持召开＋议程＋报告引导语 | 本期有来源的主持人信息优先，否则用用户确认的可配置默认主持人；议程始终取本期 |
| propagation | 总量及峰值、境内媒体、新媒体、境外媒体四段 | 工作簿统计；话题句用本期通稿新闻标题 `focus_title`，不拼接子议题清单、不借历史标题；来源缺失先补通稿 |
| topics | 全部子议题统计表及传播量图 | 已确认的子议题和数据；不制造情感百分比 |
| domestic | 按实际议题循环；多簇逐段用“一是、二是”，单簇直接成段 | 模型选择、分组、独立核验的判断及依据 |
| comments | 固定引导句＋按真实具体观点分点＋真实原话 | 同题可有不同诉求；同题同判断用模型审核的相同heading合组，不强制一个议题只有一个点；无原话不补造 |
| hotwords | “从热词分布来看”＋词云 | 已审核词语及对应判断，不从图片大小推断词频 |
| overseas_media | 事实报道句＋另段解读 | 实际类别、简体来源标题、原文分析 |
| overseas_comments | 有原话则分组，无可引用观点则使用用户指定固定句 | 审计保留真实检索状态，固定编辑措辞不充当采集或情感认证 |
| overseas_table | 序号、来源、报道日期、超链接标题 | 已审核外媒报道 |
| wechat_table | 固定TOP表头与样式 | 已审核TOP，不据此限制正文选材 |

各区用唯一 `CWH_<slot>` Word 书签标识。脚本填入完整段落、表格和图片，固定章节直接取自模板；在同一 OOXML 包操作以保留图片和超链接。审计保存模板 SHA-256 和填充区列表。缺失、重复或错序书签不能静默退回空白文档。

评论模型只写逐条分类、选句、具体观点heading及独立复核结论，不再生成冗余topic_headings索引。CSV兼容列topic_comment_heading由脚本按已核验议题编号映射本期完整题名，不进入正文、不充当语义审核；正文只用审核通过的逐条标题。旧返回的索引保留日志但不参与通过判定，实际缺失原话、标题、编号或审核结论仍拦截。

评论开头按三份基准共同写法，只举两类已审核观点，再接“等。主要评论如下”，不把全部分点标题堆成目录。脚本按已有顺序优先选不同议题的两类，只有同一议题时可选其不同判断；不删改正文其他评论，不硬截标题，不把“认为”删去或改成“肯定”。

## 固定句式

通用证据规则维护于 `config/formal_writing_rules.v1.json`；用户确认的固定句式单独维护于 `config/editorial_template.v1.json`。共享加载器合并两者，Word、Markdown 和各模型任务共用。不让模型再润色脚本句式。

- 开头保留用户确认的“国务院总理李强……主持召开……”格式；姓名是独立配置，不写进算法。本期有来源的主持人信息优先，其他任期须提供本期信息或调整配置。动作议程与仅有议题名称的输入分开处理。
- 保留用户确认的“本次常务会引发境内外媒体广泛报道”“人民网、新华网、央视网等均在显著位置刊文”和无境外评论时的指定句。它们属于编辑措辞，审计记录来源模板哈希，不据此改变原始数量、采集状态或情感标签。
- 主体句为“完整机构／职务／姓名＋称／建议／指出等＋具体观点”，优先忠实摘用原文，可删除无关重复，不硬凑判断、依据、适用范围。单个主体的一项观点通常50—120字，优先80—100字，上限150字（不含归因前缀，含标点、不计空白）。超长在冻结前依据原文精简并独立复核，不能截句；无法忠实精简的全文保留备选并记录缺口。媒体自身分析与受访专家分开归因。中性归因前缀默认“称”，不把标题的态度动词照搬到每条引述；原文内已有的归因和具有具体含义的建议、预计等不机械替换。
- 判断及理由、效果及条件、障碍及建议、变化及含义是可选句式，不是每题必填四类。重复判断择优，不把批评改成肯定。按用户最新编辑要求，同一信源全篇最多引用两次，且须在不同议题提供不同有效观点；其余有效观点保留在工作台，不冒充未发现。这是当前编辑约束，不宣称三份基准没有例外。
- 每个议题顶层标题用“态度动词＋议题对象＋概括判断/意义”，覆盖下文，不用裸议题名称或只覆盖第一簇的具体措施。通常肯定、认可、认为、建议；态度由证据决定。一个议题只有一组观点时直接成段；如果分“一是、二是”，每个点至少两个不同主体。单个扎实来源仍有效，不为凑数伪造第二来源或硬并不相干观点。
- 正式表格的完整议程名称与检索关键词分开：本期通稿识别并核对过的`topic_aliases`同时进入真实检索计划，政策解读用前两个短概念作OR检索，保留官方通稿核实通道的完整题目。开放检索至少有一条不强制“国常会”字样；候选是否与本期相关仍须读原文核实，不因命中关键词直接入稿。不借用基准报告或其他期次的别名。
- 不写“援引业内人士观点称”等匿名转述。能回原文找到具体专家就写完整署名；只有媒体自己的分析才归给媒体，无法核实的匿名转述留作备选。
- 每个议题下只要有多个正文段落，就逐段使用“一是、二是……”。每个分点至少两个有效独立主体，所有样本连在该分点同一段内，不按字数或样本数自动另起无编号段落。只有整题一个观点组时才直接写一个无编号段落。
- 多组中来源不足的组，先在作者阶段补选或按实际共同判断重新分组；形状合格的首次汇总可在既有90秒预算内局部重组一次（最多45秒，不额外重读全文）。无法完成时保留原有选择并记录编辑缺口，不能由脚本擅自只留第一组、伪造来源、硬并观点或靠隐藏全部序号解决。仅经独立核验的观点可进入有缺口生成稿；来源不足的编号组仍不能算写作达标。模型明确不选的完整观点保留备选。独立复核后仍须重新核数；旧审核材料的隔离重渲染保留全部冻结观点，不伪称已完成新规则下的重新选材。
- 限时正文选材按信息增量而非来源数量：同一判断通常选两个有实质补充的主体；单一来源只能在整题一个组的直接成段情形使用，不豁免多段时每点至少两来源的排版要求。新增来源须补充尚未覆盖的机制、条件、依据、对象或不同意见；换措辞重复同一结论、数据、例子而无增量的留作备选。第三个及更多主体须确有不可替代的增量；不为压篇幅删掉不同意见、必要限定。仍由模型选已有观点编号，脚本不判断语义重复、不截断原话。
- 境外事实报道和解读分开：事实性报道通常列3—4个真实“来源《标题》”，不足不补造；无解读接“暂无评论性文章”，有解读接“少量解读如下”，另段写“态度动词＋判断。来源《标题》称，具体观点”。多组解读逐段用一是、二是。缺少评论时使用指定编辑句，不制造原话。技术过程、审核理由和预算放工作台与审计，不进入成稿。
- 热词段依次填“从热词分布来看，‘词1’‘词2’‘词3’等词位居前列，舆论＋有依据的态度判断”“……等词热度较高，舆论……”“……等词备受关注，舆论……”“此外，……等词也受到关注，舆论……”。实际使用中文双引号；每组一般3—4个词、最多5个，取已审核词语，不凑数。这是用户确认的编辑模板，不据此创造词频数字、时间趋势或原材料没有的态度。

人工审核原文件绝不覆盖。`import_reviewed_template` 必须核对已读审核稿哈希，将“有几个子议题就有几个点”等说明转换为程序规则并移出正式模板；任何未绑定槽位的额外说明会被验证器拦截，不能混进成稿。占位均使用“具体观点”。

## 固定版式

三份基准共用 A4 竖版，上下约72 pt、左右约90 pt；模板保留精确测量值。标题华文中宋22 pt，一级黑体16 pt，二级楷体_GB2312 16 pt加粗，正文仿宋_GB2312 16 pt、首行两字。Title样式、表格、链接、图片宽度均由脚本固定。

单处引述通常50—120字，优先80—100字，上限150字。字数约束在冻结前处理，不由渲染器截断审核后的观点。一组一个自然段，含“一是／二是＋总结句＋样本甲＋样本乙（及有增量的其他样本）”；不因超过300字或两个样本而自动拆段。整段显得臃肿时回到作者选材与精简处理，不把排版换行冒充语义优化。分组失败只保存工作台候选，不再生成source_order正文；独立复核后不足两来源的多组稿仍须补选或重新分组，不能称为高质量正式成稿。

限时正文每题常规2—3个不同判断、4—6处引述。引述处数与独立主体数分开计；全篇总条数、段数随议题和证据变化，不设历史数量配额。丰富议题可增加，但每条须有不可替代的信息增量；薄弱议题不凑数。检索及阅读池不缩小，超常规只作编辑提醒，不由脚本按字数删观点。旧12主体及6组上限仅作异常兜底，不是常规写作目标。

报告两图使用 `config/report_visual_style.v1.json` 和 `scripts/cwh_report_visuals.py`，不是有监测原图就直接嵌入。标题固定为“X月X日国务院常务会议舆情走势”和“X月X日国务院常务会议子议题传播量”，日期取本期；主标题、总量副标题、字体、#003366蓝色、线宽、灰色网格端点、图例、细横条、单位及位置固定。子议题按真实数量稳定降序，完整议题换行，必要时按固定规则增高，不截字；“万”保留一位小数、去掉末尾零。折线峰值仅标真实最大值，坐标上限按固定刻度算法取值。两图带当前数据/配置/图片哈希清单，明确程序模板来源，不冒充监测原图。工作台使用同一图片，原监测图仅保留作审计。微软雅黑常规及粗体是精确字体依赖；非Windows须用CWH_CHART_FONT/CWH_CHART_BOLD_FONT指定已安装的真实字体，禁止悄悄换字体。腾讯字体词云逻辑不变，限高三英寸、自然分页。

子议题表直接克隆 `templates/topic_table.xml`：三份基准相同的九列网格、两行合并表头、微软雅黑11pt、黑色半磅边框。数字居中，完整议题换行。显式固定首行缩进为0、行距31.2pt（基准网格效果），不继承正文缩进。始终保留正面/中立/负面三列；未审核或分母不足时留空，不能为了表格完整填百分比。行数取本期议题，不写死六行；行高随内容增长，不继承某期首行的特定最小高度。当前基准展示名固定为“境内主流媒体”，对应统计列仍是“境内新闻”；展示名称映射不代表完成来源级重分类，不因改表头调整数值，原始口径及差异保留审计。

标题与下一段、连续表头与第一行数据保持相邻，避免标题孤悬页尾。Word 的非打印段落标记不是报告内容，不能为了隐藏界面黑方块而删掉必要分页属性。正文来源加粗按已知主体字段与归因动词定位，不用全局正则把观点中“提到、强调”等词误当发言人。

## 验收

脚本检查槽位、章节、无残留占位、表格、图片关系、评论和保留观点不丢失；另做页面渲染检查。真实历史结果隔离重渲染只是模板兼容性验证，不是模型重新跑通的证据。

显式 `section_overrides` 保留用户自定义内容，标记 `explicit_section_override`，不得伪称模板填空已通过。生成文档另存，不覆盖旧交付与原始资料。

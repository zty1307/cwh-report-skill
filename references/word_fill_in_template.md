# 通用 Word 填空模板

正式生成使用 `templates/cwh_fill_in_template.docx`。不让模型修改 Word、设计章节、配色或图形，不把基准报告当本期事实。`scripts/cwh_docx_template.py` 是开发维护工具；正常运行只加载随 Skill 打包的 Word。

## 谁填什么

| 填充区 | 固定部分 | 本期输入及依据 |
| --- | --- | --- |
| title | 日期＋国务院常务会议舆情综述 | 会议日期，不用提交日 |
| opening | 主持召开＋议程＋报告引导语 | 本期有来源的主持人信息优先，否则用用户确认的可配置默认主持人；议程始终取本期 |
| propagation | 总量及峰值、境内媒体、新媒体、境外媒体四段 | 工作簿统计；优先有来源的 `focus_title`，否则固定话题句填本期明确议题，不借历史标题 |
| topics | 全部子议题统计表及传播量图 | 已确认的子议题和数据；不制造情感百分比 |
| domestic | 按实际议题循环；多簇逐段用“一是、二是”，单簇直接成段 | 模型选择、分组、独立核验的判断及依据 |
| comments | 固定引导句＋按全部子议题逐项展示＋真实原话 | 已审核评论；无可引用原话的议题保留简短说明，不补造观点 |
| hotwords | “从热词分布来看”＋词云 | 已审核词语及对应判断，不从图片大小推断词频 |
| overseas_media | 事实报道句＋另段解读 | 实际类别、简体来源标题、原文分析 |
| overseas_comments | 有原话则分组，无可引用观点则使用用户指定固定句 | 审计保留真实检索状态，固定编辑措辞不充当采集或情感认证 |
| overseas_table | 序号、来源、报道日期、超链接标题 | 已审核外媒报道 |
| wechat_table | 固定TOP表头与样式 | 已审核TOP，不据此限制正文选材 |

各区用唯一 `CWH_<slot>` Word 书签标识。脚本填入完整段落、表格和图片，固定章节直接取自模板；在同一 OOXML 包操作以保留图片和超链接。审计保存模板 SHA-256 和填充区列表。缺失、重复或错序书签不能静默退回空白文档。

## 固定句式

通用证据规则维护于 `config/formal_writing_rules.v1.json`；用户确认的固定句式单独维护于 `config/editorial_template.v1.json`。共享加载器合并两者，Word、Markdown 和各模型任务共用。不让模型再润色脚本句式。

- 开头保留用户确认的“国务院总理李强……主持召开……”格式；姓名是独立配置，不写进算法。本期有来源的主持人信息优先，其他任期须提供本期信息或调整配置。动作议程与仅有议题名称的输入分开处理。
- 保留用户确认的“本次常务会引发境内外媒体广泛报道”“人民网、新华网、央视网等均在显著位置刊文”和无境外评论时的指定句。它们属于编辑措辞，审计记录来源模板哈希，不据此改变原始数量、采集状态或情感标签。
- 主体句为“完整机构／职务／姓名＋认为／称／建议＋具体观点”，优先忠实摘用原文，可删除无关重复，不硬凑判断、依据、适用范围。单个主体的一项观点参考100—200字（不含归因前缀，含标点、不计空白）；短而完整不扩写，必要条件不截断。媒体自身分析与受访专家分开归因。
- 判断及理由、效果及条件、障碍及建议、变化及含义是可选句式，不是每题必填四类。重复判断择优，同人不同判断保留，不把批评改成肯定。
- 限时正文选材按信息增量而非来源数量：同一判断通常选2—4个有实质补充的主体，不是最低配额或脚本硬上限。新增来源须补充尚未覆盖的机制、条件、依据、对象或不同意见；换措辞重复同一结论、数据、例子而无增量的留作备选。超过4个主体须确有不可替代的增量；不为压篇幅删掉不同意见、必要限定或同人的其他独立判断。仍由模型选已有观点编号，脚本不判断语义重复、不截断原话。
- 境外事实报道和解读分开，按实际分布选择引导语。缺少评论时使用指定编辑句，不制造原话。技术过程、审核理由和预算放工作台与审计，不进入成稿。

人工审核原文件绝不覆盖。`import_reviewed_template` 必须核对已读审核稿哈希，将“有几个子议题就有几个点”等说明转换为程序规则并移出正式模板；任何未绑定槽位的额外说明会被验证器拦截，不能混进成稿。占位均使用“具体观点”。

## 固定版式

三份基准共用 A4 竖版，上下约72 pt、左右约90 pt；模板保留精确测量值。标题华文中宋22 pt，一级黑体16 pt，二级楷体_GB2312 16 pt加粗，正文仿宋_GB2312 16 pt、首行两字。Title样式、表格、链接、图片宽度均由脚本固定。

段落以480字、两条完整判断为排版软上限，只在下一条完整判断之前换段，不截断条件或观点。同一观点组可以有多个自然段，不因此造新标题。单个必要判断超长时保留全文。物理分段不等于语义分组完成，source_order恢复稿仍有编辑缺口，不能称为高质量正式成稿。

图表优先原监测图；空文件或损坏图片不算原图。子议题兜底遵循 `config/chart_style.v1.json`：深蓝横条、数量降序、同量稳定排序、一位小数“万”、完整标签换行。程序图明确标记来源，不能冒充原图。图片不超版心；腾讯字体词云限高三英寸，自然分页，不强制独占一页。

标题与下一段、连续表头与第一行数据保持相邻，避免标题孤悬页尾。Word 的非打印段落标记不是报告内容，不能为了隐藏界面黑方块而删掉必要分页属性。正文来源加粗按已知主体字段与归因动词定位，不用全局正则把观点中“提到、强调”等词误当发言人。

## 验收

脚本检查槽位、章节、无残留占位、表格、图片关系、评论和保留观点不丢失；另做页面渲染检查。真实历史结果隔离重渲染只是模板兼容性验证，不是模型重新跑通的证据。

显式 `section_overrides` 保留用户自定义内容，标记 `explicit_section_override`，不得伪称模板填空已通过。生成文档另存，不覆盖旧交付与原始资料。

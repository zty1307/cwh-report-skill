# CWH 自动化需求拆解

## 带教确认后的真实诉求

正式数据由部门舆情监测系统给出。CWH 自动化不负责用自建爬虫复刻全量数据，而负责把系统导出的固定数据自动加工成 Excel、图表和正式 Word 报告。

正式输入包括：

1. 国务院常务会议议题或通稿；
2. 系统汇总工作簿；
3. 系统媒体、自媒体和网民评论明细；
4. 必要时的情感分析复核结果。

## 报告固定模块

1. 整体传播：境内主流媒体、新媒体、境外媒体、总量、逐日走势。
2. 子议题传播：每个议题的境内媒体、新媒体、境外媒体、总量、正中负比例。
3. 境内舆论：按议题归纳媒体、自媒体和专家观点，并保留证据。
4. 网民评论：保留真实原话、平台、时间和链接。
5. 热词：优先采用系统/分析人员候选词，自动完成去重、归类和制图。
6. 境外舆论：区分转载、一般解读和借题炒作。
7. 附录：外媒表、公众号 TOP、证据清单。

## 权威口径

- 系统总量和趋势不得用爬虫样本数覆盖。
- 总事件全局去重；子事件允许重复命中，不能相加推算总事件。
- 系统关键词、排除词、事件 ID 和监测窗口直接沿用。
- 系统情感标签和比例仅作审计参考；正式情感比例必须由 `large-scale-sentiment-analysis` 对原始评论重新分析并回灌。

## 自动化边界

自动完成：系统表解析、字段标准化、公式核验、观点聚类、评论筛选、情感回灌、热词整理、图表、Excel、Word、审计。

人工复核：敏感表述、境外炒作分类、代表性评论是否适合引用、最终公文语气。

MediaSpider 和 agent-reach 只保留为补充检索或研发验证工具，不属于正式数据主流程。

## 验收

- 系统值在 `report_data.json`、生成 Excel 和 Word 中一致；
- 不设置爬虫样本数量门槛；
- 缺少明细时明确要求补导对应系统数据；
- 不编造观点、评论、传播量或情感比例；
- 最终输出一份正式 Word、一份配套 Excel 和结构化审计文件。
